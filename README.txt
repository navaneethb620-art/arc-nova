# ARC-NOVA Website

A responsive, static HTML/CSS/JavaScript website for ARC-NOVA.

## Run locally
Open `index.html` in a browser. For best results, use a local static server:
- VS Code: install Live Server and open `index.html`
- Or run `python -m http.server 8000` in this folder and visit http://localhost:8000

## Deploy free with Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to Vercel using GitHub.
3. Import the repository.
4. Framework preset: Other; Build command: leave blank; Output directory: `.`.
5. Deploy. Vercel will provide a free `*.vercel.app` address.

## Before public launch
- Confirm the phone/WhatsApp number and update it if needed.
- Replace reference images unless you have commercial usage permission. The current reference photos were supplied by the site owner as Google-image examples; their reuse rights have not been verified.
- Confirm every advertised feature is currently deliverable. In particular, remove the drag-and-drop service card if it is not ready for client projects.
- Add an actual business email if desired.
- Add a favicon/logo if available.

No video section is included, as requested. VR is described only as a future direction.

The homepage hero uses the ARC-NOVA SVG logo instead of a bedroom photograph. Logo file: assets/arc-nova-logo.svg
